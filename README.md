# スーパー精錬シミュレーター

スマートフォン向けのブラウザミニゲームです。依存パッケージはありません。

## 起動

```sh
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開いてください。

## 遊び方

開始画面で手持ちの火晶数を入力し、モードを選びます。

- **日次モード**: 月曜日から始まり、ボタンで翌日に進みます。素材を使う火晶の精錬と、スーパー精錬を実行できます。曜日別に火晶の獲得数、消費数、精錬火晶の獲得数を表示します。
- **省略モード**: 月曜日から日曜日までのスーパー精錬回数を入力し、1週間分をまとめて抽選します。必要な火晶数、曜日別の獲得数、週間合計を表示します。火晶そのものの精錬はこのモードでは行いません。

## ルール

- 火晶の精錬: 肉・木・石炭・鉄を各50,000消費し、1日8回まで実行できます。獲得数は1〜5個で、確率は順に40%、30%、15%、10%、5%です。
- スーパー精錬: I〜Vの消費火晶は1回あたり20、50、100、130、160個で固定です。毎日最初の1回は消費が半分です。
- スーパー精錬の獲得確率は20回ごとに切り替わり、週に最大100回までです。日次モードの複数回精錬では、現在の段階の残り回数まで選べます。
- 日次モードの素材は各2,800,000個から開始します。これは7日間、毎日8回の火晶精錬を試せる量です。
- シミュレーションの日付は実際の日付に連動しません。進行状況はブラウザのローカルストレージに保存されます。「新しく始める」で結果を消しても、開始火晶数と省略モードの曜日別回数は残ります。
